# Прогнозирование погоды

Цель: после окончания сегодняшнего дня предсказать максимальную температуру завтра по 30 предыдущим дням.


## Загрузка данных

Из папки `sem2/lab8`:

```bash
uv sync
uv run python -m lab8.utils.download_data
```

Загрузчик `src/lab8/utils/download_data.py` использует `KaggleApi`, скачивает и
распаковывает датасет в `data/raw`. Если непустой `seattle-weather.csv` уже есть,
скачивание пропускается. Пути вычисляются относительно файла загрузчика.

Для авторизации используются настройки Kaggle на машине. При необходимости
переменные `KAGGLE_API_TOKEN` либо `KAGGLE_USERNAME` и `KAGGLE_KEY` можно задать
в `.env` в папке `lab8`. Поддерживается и стандартный файл `~/.kaggle/kaggle.json`.
Настройки и ключи не нужно вставлять в ноутбук.

## Первый ноутбук

Откройте `notebooks/01_visualization.ipynb`, выберите Python из `.venv` лабораторной
и выполните ячейки по порядку. Все импорты находятся в первой кодовой ячейке.
Ноутбук только читает локальный CSV; загрузка выполняется отдельной командой выше.
Графики, признаки, масштабирование, создание окон и сохранение разделены на шаги.
Результаты для следующих ноутбуков сохраняются в `artifacts/`.
