Задание по лабораторной работе №2
1.	Необходимо с использованием моделей искусственных нейронных сетей построить зависимость вида Y = f(X1, X2)
2.	Для этого необходимо использовать синтезированный датасет, имеющий следующую структуру: 
Tsys	Out1	Out2	In1	In2	In3	In4	In5	In6.
3.	Предполагается построение двух моделей:
- зависимость Out1 = f(In1, In2) или Out1 = f(In1, In3);
- зависимость Out2 = f(In1, In2) или Out2 = f(In1, In3).
Примечание. Данные для одной из моделей более шумные и имеют выбросы.
4.	Типовой вид реализуемой зависимости приведен на следующем рисунке и называется поверхность типа “седло”.
5.	При формировании датасета и последующей проверки данные можно разделить в соотношении 90% для формирования обучающей выборки и 10% для формирования тестовой выборки.
6.	При реализации задания необходимо оценить погрешности аппроксимации поверхности.
